# sensor-display Specification

## Purpose
Отображение выбранных датчиков и пользовательских статусов в средней строке главного экрана.

## Requirements

### Requirement: Плитки датчиков и статусов
Средняя строка SHALL содержать по одной плитке на каждый выбранный в настройках элемент
в сохранённом порядке. Плитка SHALL показывать название (мелко, одна строка) и значение
(крупно, по центру, размер шрифта подбирается под размер плитки).

#### Scenario: Данные ещё не загружены
- **WHEN** состояние устройства ещё не получено
- **THEN** плитки показывают «…» и «—»

#### Scenario: Элемент пропал из устройства
- **WHEN** сохранённый элемент отсутствует в ответе устройства
- **THEN** плитка показывает «Нет данных»

### Requirement: Значения датчиков
Значение датчика SHALL формироваться так:
- `status = failure` → «Нет связи»;
- дискретные типы с известным `triggered`: opening «Открыто/Закрыто», motion «Движение/Нет движения»,
  leakage «Протечка!/Сухо», smoke «Дым!/Норма», gas «Газ!/Норма», boiler_failure «Авария/Норма»,
  room_thermostat «Запрос тепла/Нет запроса», прочие «Сработка/Норма»;
- иначе числовое `value` (до 1 знака после запятой) с `unit` или единицей по умолчанию
  (temperature «°C», voltage «В», pressure «бар», humidity/modulation «%»).

#### Scenario: Температура
- **WHEN** датчик типа temperature со значением 21.5 и без unit
- **THEN** плитка показывает «21.5°C»

### Requirement: Значения пользовательских статусов
Для `controls.statuses` и `controls.toggle_buttons` значение SHALL браться из
`name.active_label` при `active = true` и из `name.inactive_label` иначе
(по умолчанию «Вкл»/«Выкл»).

#### Scenario: Статус ворот
- **WHEN** статус «Ворота гаража» неактивен и `inactive_label = "Норма"`
- **THEN** плитка показывает «Норма»

### Requirement: Цвет значения
Цвет значения SHALL отражать уровень: норма — зелёный, активный статус — синий,
`alarm` — красный, `silent_alarm` или сработка — оранжевый, нет связи — серый,
неизвестно — основной цвет текста.

#### Scenario: Тревога по датчику
- **WHEN** датчик имеет `status = alarm`
- **THEN** значение отображается красным
