# scenario-execution Specification

## Purpose
Запуск выбранных сценариев и пользовательских кнопок прибора из нижней строки главного экрана.

## Requirements

### Requirement: Кнопки сценариев
Нижняя строка SHALL содержать по одной крупной кнопке на каждый выбранный сценарий/кнопку
в сохранённом порядке, с названием из устройства (до 2 строк, автоподбор шрифта).

#### Scenario: Сценарий не найден
- **WHEN** сохранённый сценарий отсутствует в ответе устройства
- **THEN** кнопка показывает «Не найден» и неактивна

### Requirement: Запуск сценария
Нажатие кнопки SHALL сразу (без подтверждения) отправлять:
для сценария — `POST /devices/{id}/scenarios/{scenario}/actions/activate`;
для пользовательской кнопки — `POST /devices/{id}/controls/{button}/actions/trigger`.
Во время выполнения SHALL показываться «Запуск: <название>…», а все кнопки команд SHALL быть
неактивны. После успеха SHALL показываться «Выполнено: <название>» и включаться
ускоренное обновление состояния.

#### Scenario: Успешный запуск
- **WHEN** пользователь нажимает «Активировать ворота гаража»
- **THEN** отправляется команда активации сценария
- **AND** показывается «Выполнено: Активировать ворота гаража»

#### Scenario: Ошибка запуска
- **WHEN** API возвращает `ok: false`
- **THEN** показывается текст ошибки, кнопки снова становятся активны

### Requirement: Обновлённое состояние из ответа команды
Если ответ команды содержит объект `device`, приложение SHALL сразу отрисовать его;
иначе SHALL запросить состояние заново.

#### Scenario: Ответ с устройством
- **WHEN** ответ команды содержит `device`
- **THEN** экран обновляется без дополнительного запроса
